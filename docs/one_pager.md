# MedAlignFlywheel｜医疗多模态数据质量与评测

**岗位方向：蚂蚁健康·全模态大模型数据。** 基于公开医学图文数据 ROCOv2，构建可复现的数据治理与评测流水线，回答“数据是否可用、评测是否可信、数据选择是否带来收益”。个人求职项目，与蚂蚁集团无关联。

## 技术闭环与工程贡献

`来源与许可核验 → 质量算子与血缘 → 近重复检查 → BiomedCLIP图文检索 → 难例挖掘 → 等预算数据选择对照`

- **数据工程**：图像、文本、配对、医学概念、近重复、血缘六类算子；逐样本记录来源、SHA256与处理结论。1,000条开发样本清洁后保留990条。
- **评测工程**：真实预训练权重前向、候选规模对照、bootstrap区间、配置冻结；发现旧55条holdout参与过开发后，将其废弃，另取1,000条未用于本项目开发的样本。
- **数据飞轮**：挖掘229条待人工复核难例；等预算比较随机、质量过滤、困难优先、长尾优先四种策略，检验子集结构变化是否转化为训练收益。

## 有记录的实验结果

| 实验 | 结果与证据 |
|---|---|
| 新增评测样本，200候选 | 图→文R@1 **0.810**，95% CI **[0.755, 0.860]** |
| 同一批样本，500 / 1,000候选 | 图→文R@1 **0.666 / 0.587**，展示候选规模对难度的影响 |
| 合成质量缺陷探针 | 5个预期可检缺陷全部识别；8个清洁对照无误报；另有ID冲突未自动识别的已知缺口 |
| 对齐头对照（原200候选测试集） | 冻结基线 **0.805**；随机/质量过滤 **0.578**、困难优先 **0.507**、长尾优先 **0.527**（多种子均值） |

**结论：在冻结编码器、每策略200个训练样本的小规模实验中，训练后的四种策略均低于基线，没有证实数据选择带来训练增益。** 检索能力主要来自BiomedCLIP预训练；本项目贡献是数据工程、评测链路、错误定位与可追溯实验。

## 结论边界

- 新增样本与开发集ID零重叠，但存在2个跨集近重复；无法按来源论文分组。BiomedCLIP预训练数据与ROCOv2可能重叠，不能宣称纯净零样本泛化。
- 自包含模型已核验词表、配置与权重加载，但与官方全塔前向的逐向量等价性仍为 **BLOCKED**。
- 数据是公开论文图像及图注，并非医院诊断报告；ROCOv2适用CC BY-NC-SA 4.0及来源条款。难例和规则筛选的负例未经临床专家确证。
