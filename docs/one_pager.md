# MedAlignFlywheel · 一页中文介绍（最终版）

**项目定位**：面向蚂蚁健康「全模态大模型数据」岗位的求职作品集——用公开医学多模态数据 ROCOv2，
端到端搭建「合规摄取 → 六维质量评估 → 真实跨模态检索评测 → 高价值数据飞轮 → 严格独立验证」的可复现流水线，
证明候选人在**多模态数据工程建设、质量评估方法论、数据选择策略与实验纪律**上的实战能力。

---

## 核心亮点（均为已验证结果）

1. **合规与防泄漏**：ROCOv2（CC BY-NC-SA 4.0）行级抽样，记录 SHA256/许可/出处；跨切分近重复泄漏检测（修复后假泄漏 71→0）；最终评价使用**1000 条从未参与开发的独立样本**，与开发集零重叠。
2. **可审计的质量与血缘体系**：六大质量算子（图像/文本/配对/CUI/近重复/血缘），合成缺陷测试 **5/5 自动识别、8/8 清洁样本 0 假阳性**。
3. **真实检索评测 + 严格实验纪律**：真实 BiomedCLIP 前向，在独立测试集上 200/500/1000 候选给出 R@1=**0.810/0.666/0.587**（AUROC 恒 ≈0.997），**配置先冻结、只评价一次**。
4. **诚实的边界结论**：数据选择能改变子集结构，但**训练增益未被证实**（四种策略均低于冻结基线）；229 条难例**无一条**被确认为医学错配——不把未验证的推断写成结论。

## 三条简历描述（适合蚂蚁健康 · 全模态大模型数据岗位）

1. **构建医疗多模态数据质量与血缘体系**：基于公开 ROCOv2（CC BY-NC-SA 4.0）实现图像/文本/配对/概念/近重复/血缘六大质量算子，引入跨切分近重复泄漏检测（假泄漏 71→0）；以合成缺陷注入验证算子有效性（5/5 自动识别、0 假阳性），每条样本记录 SHA256、来源与算子结论，支撑数据可审计、可追溯。

2. **建立严格的跨模态检索评测与独立验证机制**：用真实 BiomedCLIP 权重做图文检索评测，在**1000 条从未参与开发的独立样本**上给出 200/500/1000 候选规模的 R@1=0.810/0.666/0.587（95% bootstrap CI）与 AUROC≈0.997；实行"配置先冻结、只评价一次"的纪律，并显式披露来源重叠、多对多正确配对、预训练数据潜在重叠三类限制。

3. **以数据飞轮发现模型困难并完成诚实的价值度量**：挖掘并分类 229 条模型困难案例（模型排序错误 214 / 边界正例 15）、构造 1,218 条三重校验难负例，对比四种数据选择策略对子集结构的影响（困难样本占比 27%→83%）；同时通过对照实验给出边界结论——**本规模下数据选择的训练增益不可见**，且未人工复核的困难负例不冒充确定错配，体现数据岗位所需的度量严谨性。

## 已证明 vs 仍属探索（面试口径）

- **已证明**：合规摄取与泄漏防护、质量算子有效性、真实检索评测、困难样本发现与分类、实验纪律与 bug 定位修复能力。
- **仍属探索（未获证实）**：数据选择的训练收益、困难/长尾样本的实际价值、自包含前向与官方的严格等价性。
- **预训练能力 vs 本项目贡献**：0.81 的跨模态对齐来自 BiomedCLIP 预训练；本项目贡献是数据侧的工程、度量与纪律。
