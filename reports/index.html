医疗多模态数据对齐 · 质量评估 · 高价值数据飞轮　|　求职项目（蚂蚁健康 · 全模态大模型数据）

0 · 项目概览

本项目以公开数据集 ROCOv2（医学影像+图注+CUI） 为基底，构建一条可复现的医学多模态数据流水线： P0 合规摄取与跨集泄漏检查 → P1 六大质量算子 → P2 用真实 BiomedCLIP 权重做跨模态检索评测 → P3 数据飞轮（难例挖掘/难负例构造/四种数据选择） → P4 冻结编码器+小对齐头对照。 所有真实权重均通过严格门禁加载（zero-missing/zero-unexpected + 指纹），检索评测在 冻结 test 集 上进行，禁止据 test 调参。

冻结 BiomedCLIP 编码器已在本任务上接近天花板（test I2T R@1≈0.81）。仅训 200 样本小对齐头对数据选择策略的区分力有限；本实验如实报告，不夸大差异。

诚实结论：在已接近天花板的冻结编码器上，仅用 200 样本训练小对齐头会过拟合并拖累检索 （0.81→0.57）；困难/长尾优先的 C/D 比随机 A/B 更差。说明本规模 + 冻结编码器下，数据选择的增益不可见， 需全参微调或更大数据才显形。P4 的价值在于给出这一边界结论，而非宣称某策略更优。

6 · 完整性与可复现性

  • 权重指纹：BiomedCLIP 官方 HF microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224； 文件 SHA256 与张量级 SHA256 见 reports/embedding_run.json，加载模式 strict zero-missing zero-unexpected。
  • 冻结纪律：test 集仅用于最终评测，不参与 P1 调参、P3 挖掘/选择、P4 训练。
  • 负例净化：模糊负例（146 个）不计入 AUROC，如实公开。
  • 非伪造纪律：相似度全部来自真实前向推理；任何未实际运行的模块在文档中标注 NOT_TESTED。
重要更正记录：初版检索出现 AUROC<0.5 与 R@1 异常偏低，根因是 ① 自包含 ViTBlock 前向的预归一化顺序写错（已修正为 x = x + mlp(norm2(x))）， ② auroc_rank_based 计数方向反了（已修正为统计 neg<pos）。修正后指标恢复至上述真实水平，说明评测链路可信。
